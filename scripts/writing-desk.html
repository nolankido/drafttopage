          Before you copy: inspect the handoff

          These local checks cover some formatting limits and unfinished writing patterns. They do not verify facts, grammar, permissions, or URLs. Use each finding to select its current article passage. Nothing changes automatically.

            How to paste these blocks in WordPress
            1. Create a new, empty draft post in WordPress. Enter your article title in its title field.
            2. Open the editor Options menu, select Code editor, and paste the copied blocks into the post body. This is for the block editor, not a Custom HTML block or the Classic Editor.
            3. Return to Visual editor. Inspect headings, lists, tables, quotes, and links. Inspect linked images, rebuild unsupported content, and add page fields before previewing the post.

            The body becomes editable blocks. The title, excerpt, description, source notes, and review questions are excluded. Images stay as text unless you explicitly select supported linked images above. Complex Markdown stays as text; rebuild it in WordPress. Numbered lists preserve their starting value. Unsupported list groups stay intact as text. Nothing connects to your WordPress account. WordPress handoff help (new tab)
