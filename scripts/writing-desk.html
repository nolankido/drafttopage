        Preview formats and limits

        For an underlined heading, put one or more = characters (H1) or - characters (H2) on the next line after an ordinary paragraph. A blank line before three or more identical -, *, or _ markers makes a thematic break. Spaces between break markers are allowed. Use at most three leading spaces; headings and breaks inside lists or quotes are outside this subset. In imported Markdown files, a first line of --- starts front matter; use *** for an opening break.

        Headings (both # markers and ordinary paragraphs underlined with = or -), top-level thematic breaks, nested lists, nested single-line bold and italic text, code, quotes, and simple pipe tables. Lists preserve starting numbers and support six levels and 200 single-line items per continuous group. Tables support up to 12 columns and 100 data rows; every row must have the same column count. Inline links with an absolute http:// or https:// address open a new tab when selected; no address is loaded until then. Safe link labels can contain emphasis and code. Images, source HTML, and other link formats stay as text. Inline nesting is limited to 16 levels; multiline or overly complex inline structures stay literal. Your website can render differently.

            How to paste these blocks in WordPress
            1. Open a new, empty draft in the WordPress block editor. Put the article title in its separate title field.
            2. In Visual editor, click the empty paragraph below the title. Paste with Ctrl+V on Windows or ChromeOS, Command+V on Mac, or use the native Paste menu after tapping the empty paragraph on a phone or tablet. If the mobile clipboard permission is denied, download or manually select the reviewed block source below.
            3. Inspect the first and last paragraph, headings, lists, tables, quotes, links, and selected linked images. Rebuild unsupported content and add page fields separately.
            4. Save as a draft, close and reopen the post, and check that the blocks remain editable without unexpected-content warnings. Preview before publishing.
            If pasted source text appears
            Undo that paste, or use another empty draft, before trying again. Open the post Options menu, select Code editor, and paste the complete copied source into the empty post body. Return to Visual editor, inspect the blocks, then save and reopen. Use the full post Code editor; a Code block, Custom HTML block, or the Classic Editor serves a different purpose.
